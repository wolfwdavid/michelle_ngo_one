## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, image caption gap |
| md | 16px | Default element spacing, Rich Text paragraph margin |
| lg | 24px | Section padding, image container padding |
| xl | 32px | Layout gaps between content blocks |

| 3xl | 64px | Page-level spacing |

Source: 8-point grid default, consistent with Phase 1 Tailwind utility usage (mt-2 = 8px, py-3 = 12px observed but treated as component-specific, not a scale addition)

| Element | Style |
|---------|-------|
| `p` | 16px, weight 400, line-height 1.75, margin-bottom 16px, color gray-700 |
| `h2` | 24px, weight 600, line-height 1.3, margin-top 32px, margin-bottom 12px, color gray-900 |
| `h3` | 20px, weight 600, line-height 1.3, margin-top 24px, margin-bottom 8px, color gray-900 |
| `a` | color #4A6FA5, underline on hover |
| `ul/ol` | left padding 24px, list-disc/list-decimal, margin-bottom 16px |
| `li` | margin-bottom 4px |
| `blockquote` | left border 3px solid #4A6FA5, left padding 16px, italic, color gray-500 |
| `img` (embedded asset) | max-width 100%, height auto, border-radius 4px, margin 24px 0 |
| `strong` | weight 600 |
| `em` | italic |

Source: Standard prose styling for minimal portfolio aesthetic. Sizes drawn from the typography scale above.

## Component Visual Contracts

### ContentfulImage

| Property | Specification |
|----------|---------------|
| Wrapper | `<picture>` element with AVIF source, WebP source, and `<img>` fallback |
| srcset widths | 320w, 640w, 960w, 1280w (per D-09) |
| Default sizes attribute | `(max-width: 640px) 100vw, (max-width: 960px) 50vw, 33vw` |
| Loading | `lazy` by default, `eager` available as prop override for above-fold images |
| Fade-in animation | 300ms opacity transition triggered by svelte-inview Intersection Observer (per D-10) |
| Placeholder (while loading) | Gray-50 (#F9FAFB) background matching image dimensions via aspect-ratio CSS |
| Border radius | 4px (rounded-sm) |
| Alt text | Required prop. If Contentful asset has no description, component must still receive alt from parent. |

Source: RESEARCH.md Pattern 3, CONTEXT.md D-08/D-09/D-10

### SEO Component

| Property | Specification |
|----------|---------------|

| Required tags | `<title>`, `<meta name="description">`, `<link rel="canonical">` |

| OG image source | Project thumbnail from Contentful, transformed to 1200px wide JPG (per D-15) |

| Property | Specification |
|----------|---------------|

| Rendering method | `{@html renderedContent}` where renderedContent comes from `documentToHtmlString()` |

## Interaction Contracts

### Image Lazy Load + Fade-In

1. Image starts with `opacity: 0` and gray-50 placeholder background
2. svelte-inview fires when image container enters viewport (threshold: 0.1)
3. Image `src`/`srcset` loads (browser handles naturally with `loading="lazy"`)
4. On image `load` event, transition to `opacity: 1` over 300ms ease-out
5. Placeholder background becomes invisible behind loaded image

### CMS Content Missing Fallback

1. Load function returns data with possible `null`/`undefined` fields
2. Page component checks for data presence before rendering
3. If entire page data is missing (no entries returned): render empty state ("No content yet" + "This section is being updated.")
4. If individual fields are missing: omit that element, do not render empty containers
5. If image URL is missing: render placeholder rectangle (gray-50) at expected aspect ratio
