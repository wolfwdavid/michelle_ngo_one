    Create `src/lib/components/VideoLightbox.svelte` per D-07, D-08, D-09, VID-01, VID-02.

    **Props** (Svelte 5 $props()):
    - `projects: Project[]` -- array of projects in current category for prev/next browsing
    - `currentIndex: number = $bindable(0)` -- index of currently displayed video
    - `open: boolean = $bindable(false)` -- whether lightbox is open

    **Derived state** ($derived):
    - `current = $derived(projects[currentIndex])` -- current project
    - `videoInfo = $derived(current ? parseVideoUrl(current.videoUrl ?? '') : null)` -- parsed video URL
    - `hasPrev = $derived(currentIndex > 0)` -- show prev arrow?
    - `hasNext = $derived(currentIndex < projects.length - 1)` -- show next arrow?

    **Local state**:
    - `let modalEl: HTMLDivElement` -- bound to modal container for focus trap queries
    - `let triggerEl: HTMLElement | null = null` -- stores the element that opened the lightbox for focus restoration

    **Functions**:

    `closeLightbox()`:
    - Set `open = false`
    - Call `triggerEl?.focus()` to return focus to trigger
    - Set `triggerEl = null`

    `handleKeydown(event: KeyboardEvent)`:
    - `Escape` -> closeLightbox()
    - `ArrowLeft` -> if hasPrev, decrement currentIndex
    - `ArrowRight` -> if hasNext, increment currentIndex
    - `Tab` -> call trapFocus(event)

    `trapFocus(event: KeyboardEvent)`:
    - Query `modalEl.querySelectorAll<HTMLElement>('button:not([disabled]), iframe')`
    - Get first and last focusable elements
    - If shift+tab on first element: preventDefault, focus last
    - If tab on last element: preventDefault, focus first

    **$effect for auto-focus on open**:
    ```typescript
    $effect(() => {
      if (open && modalEl) {
        const closeBtn = modalEl.querySelector<HTMLElement>('button');
        closeBtn?.focus();
      }
    });
    ```

    **$effect to prevent body scroll when open**:
    ```typescript
    $effect(() => {
      if (open) {
        document.body.style.overflow = 'hidden';
      } else {
        document.body.style.overflow = '';
      }
      return () => { document.body.style.overflow = ''; };
    });
    ```

    **Template structure** (render only when `open && current && videoInfo`):

    Outer container: `<div class="fixed inset-0 z-60 flex items-center justify-center" role="dialog" aria-modal="true" aria-label="Video player" bind:this={modalEl} onkeydown={handleKeydown}>`

    Inside:
    1. **Backdrop**: `<div class="absolute inset-0 bg-black/85" transition:fade={{ duration: 200 }} onclick={closeLightbox}></div>`

    2. **Content wrapper**: `<div class="relative z-10 w-[90vw] max-w-[960px]" transition:scale={{ start: 0.95, duration: 200 }}>`

    3. **Close button** (top-right, above video): `<button class="absolute -top-12 right-0 flex h-11 w-11 items-center justify-center text-white hover:opacity-80 focus:outline-none focus:ring-2 focus:ring-[#4A6FA5] focus:ring-offset-2 focus:ring-offset-black rounded" aria-label="Close video player" onclick={closeLightbox}>` containing X SVG icon (24x24, stroke white, strokeWidth 2): `<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><line x1="18" y1="6" x2="6" y2="18"/><line x1="6" y1="6" x2="18" y2="18"/></svg>`

    4. **Iframe container**: `<div class="aspect-video bg-black">` containing `<iframe src={videoInfo.embedUrl} title={current.title} class="h-full w-full" allow="autoplay; fullscreen" frameborder="0"></iframe>`

    5. **Title**: `<p class="mt-3 text-center text-base font-semibold text-white">{current.title}</p>`

    6. **Prev arrow** (conditionally rendered with `{#if hasPrev}`): `<button class="absolute left-0 top-1/2 -translate-x-14 -translate-y-1/2 flex h-11 w-11 items-center justify-center text-white hover:opacity-80 focus:outline-none focus:ring-2 focus:ring-[#4A6FA5] rounded" aria-label="Previous video" onclick={() => currentIndex--}>` containing left chevron SVG: `<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><polyline points="15 18 9 12 15 6"/></svg>`

    7. **Next arrow** (conditionally rendered with `{#if hasNext}`): same pattern, right side, `translate-x-14`, aria-label "Next video", right chevron `<polyline points="9 6 15 12 9 18"/>`

    Wrap entire block in `{#if open && current && videoInfo}...{/if}` so the iframe is DESTROYED (not hidden) when lightbox closes. This is critical -- prevents audio from continuing after close.

    **IMPORTANT**: Use `onclick` (Svelte 5), NOT `on:click`. Use `$props()`, NOT `export let`. Use `$state`, `$derived`, `$effect`, NOT stores.
