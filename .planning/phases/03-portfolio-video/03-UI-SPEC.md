# Phase 3 — UI Design Contract

> Visual and interaction contract for the portfolio and video phase: homepage with hero and category sections, portfolio category pages with thumbnail grids, video lightbox/modal, project detail pages, and filmography. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (SvelteKit + Tailwind v4 CSS-first) |
| Preset | not applicable |
| Component library | none (hand-built Svelte components) |
| Icon library | Inline SVGs (play triangle, X close, left/right arrows, expand/collapse chevron) |
| Font | Inter (Google Fonts, variable weight 300-700, inherited from Phase 1) |

Source: Phase 1 UI-SPEC (design system established), CLAUDE.md (Tailwind v4 CSS-first, inline SVG icons pattern).

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps within thumbnail cards, inline padding |
| sm | 8px | Grid gap adjustments, metadata field spacing, compact padding |
| md | 16px | Thumbnail card internal padding, grid gaps (mobile), category section title margin-bottom |
| lg | 24px | Grid gaps (desktop), section heading to content spacing |
| xl | 32px | Horizontal page padding (desktop), space between category sections on homepage |
| 2xl | 48px | Major section breaks, hero to first category section gap |
| 3xl | 64px | Page-level top/bottom padding, homepage hero vertical padding |

Exceptions: Video lightbox iframe maintains 16:9 aspect ratio at max-width 960px. Lightbox close button touch target 44px. Lightbox prev/next arrow touch targets 44px. Thumbnail play overlay icon centered at 48x48px.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FFFFFF | Page backgrounds, lightbox iframe surround area (none -- dark overlay), card backgrounds |
| Secondary (30%) | #F5F5F5 | Thumbnail placeholder background (pre-load), about snippet background band, filmography table even rows |
| Text primary | #1A1A1A | Headings, project titles, body text |
| Text secondary | #6B7280 | Metadata values (role, client, year), "See all" links at rest, breadcrumb, press highlight source/date |
| Border | #E5E7EB | Thumbnail card borders, category section dividers, filmography table borders |
| Accent (10%) | #4A6FA5 | See reserved list below |
| Accent hover | #3B5D8C | Hover state for accent-colored elements |
| Overlay | rgba(0,0,0,0.85) | Video lightbox backdrop |
| Overlay text | #FFFFFF | Lightbox project title, lightbox close/prev/next icons |

Accent reserved for:
1. "See all" link hover state in homepage category sections
2. Play overlay icon fill on video thumbnails
3. Active/current breadcrumb or category indicator
4. "Back to Home" breadcrumb link hover
5. Focus ring on lightbox controls (close, prev, next)
6. Filmography "Watch" links

Accent is NOT used for: thumbnail borders, card backgrounds, section backgrounds, body text, or headings.

Source: Phase 1 UI-SPEC (color palette established), D-06 (monochrome + one accent), D-07 (dark overlay for lightbox).

## Interaction Contract

### Video Lightbox

| Interaction | Behavior |
|-------------|----------|
| Click thumbnail play overlay | Open lightbox with that video. Load Vimeo/YouTube iframe. Trap focus inside lightbox. |
| Click close button (X) | Close lightbox. Destroy iframe. Return focus to triggering thumbnail. |
| Press Escape key | Close lightbox. Destroy iframe. Return focus to triggering thumbnail. |
| Click overlay backdrop | Close lightbox. Destroy iframe. Return focus to triggering thumbnail. |
| Click prev arrow | Load previous video in category. Update title. Keep lightbox open. |
| Click next arrow | Load next video in category. Update title. Keep lightbox open. |
| Press Left arrow key | Same as click prev arrow. |
| Press Right arrow key | Same as click next arrow. |
| Tab key (inside lightbox) | Cycle through: close button, prev arrow, next arrow, iframe. Focus trapped -- does not escape to page behind. |
| Reach first/last video | Hide prev/next arrow respectively (do not wrap around). |

### Homepage Category Expand

| Interaction | Behavior |
|-------------|----------|
| Click "See all" or category heading | Expand remaining thumbnails with slide animation (300ms, cubicOut). Collapse any other open category first. |
| Click expanded category heading | Collapse expanded section with reverse slide animation. |
| Scroll to expanded content | Page scrolls naturally. Expanded content pushes subsequent sections down. |

### Thumbnail Hover

| Interaction | Behavior |
|-------------|----------|
| Mouse enter thumbnail | Scale image to 1.03 over 300ms. No other changes. |
| Mouse leave thumbnail | Scale back to 1.0 over 300ms. |

### Video Facade

| Interaction | Behavior |
|-------------|----------|
| Thumbnail visible (no click) | Shows static thumbnail image from Contentful + play overlay icon. No iframe loaded. |
| Click play overlay on homepage/category | Opens lightbox (does not navigate away). Iframe loads inside lightbox. |
| Click play overlay on project detail page | Replaces facade thumbnail with live Vimeo/YouTube iframe inline. No lightbox on detail page. |

### Navigation

| Interaction | Behavior |
|-------------|----------|
| Click breadcrumb "Home" | Navigate to homepage. |
| Click breadcrumb category | Navigate to category page. |
| Click project title in grid | Navigate to project detail page (/{category}/{slug}/). |
| Click "Learn more" in about snippet | Navigate to /about/ page. |
| Click press highlight title | Open external press URL in new tab. |

### Responsive Breakpoints

| Tablet | >= 640px (sm) | 2-column thumbnail grid |
| Desktop | >= 1024px (lg) | 3-column thumbnail grid, 2-column metadata, filmography table |

Source: D-05 through D-15, VID-01 through VID-04, PORT-01 through PORT-06.

## Accessibility Requirements

| Element | Requirement |
|---------|-------------|
| Lightbox overlay | `role="dialog"`, `aria-modal="true"`, `aria-label="Video player"` |
| Lightbox close | `aria-label="Close video player"`, `<button>` element |
| Lightbox prev/next | `aria-label="Previous video"` / `aria-label="Next video"`, `<button>` elements |
| Focus trap (lightbox) | Tab cycles only through lightbox controls. Focus returns to trigger on close. |
| Thumbnail play button | `<button>` wrapping the overlay icon, `aria-label="Play {title}"` |
| Video iframe | `title="{project title}"` attribute for screen readers |
| Breadcrumb | `<nav aria-label="Breadcrumb">` with `<ol>` list structure |
| Category expand | `aria-expanded="true/false"` on trigger element, `aria-controls` pointing to expanded panel ID |
| Thumbnail grid | Semantic `<ul>` / `<li>` list structure |
| Press highlight links | `target="_blank" rel="noopener noreferrer"` for external links |
| Focus visible | 2px accent outline (#4A6FA5), 2px offset on all interactive elements (inherited from Phase 1) |
| Color contrast | All text meets WCAG AA. White on overlay (#FFFFFF on rgba(0,0,0,0.85)): 15.4:1 (AAA). |

Source: D-09 (focus trapping), VID-02 (keyboard nav + focus trap), Phase 1 UI-SPEC (focus visible pattern).
