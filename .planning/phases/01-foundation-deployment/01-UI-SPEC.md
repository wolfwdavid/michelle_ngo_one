# Phase 1 — UI Design Contract

> Visual and interaction contract for the foundation phase: sticky header, responsive navigation, mobile drawer, footer, placeholder pages, and deployment. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (SvelteKit + Tailwind v4 CSS-first) |
| Preset | not applicable |
| Component library | none (hand-built Svelte components) |
| Icon library | Inline SVGs (4 social icons: IMDb, LinkedIn, Vimeo, YouTube) + hamburger/close icons |
| Font | Inter (Google Fonts, variable weight 300-700) |

Source: D-05 (sans-serif throughout), D-07 (Claude picks Inter — RESEARCH.md recommendation), CLAUDE.md (Tailwind v4 CSS-first, no JS config).

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding within nav items |
| sm | 8px | Compact element spacing, social icon gaps in footer |
| md | 16px | Default element spacing, nav item horizontal padding, page horizontal padding (mobile) |
| lg | 24px | Section padding, nav bar horizontal gap between items, drawer link vertical rhythm |
| xl | 32px | Layout gaps, page horizontal padding (tablet+) |
| 2xl | 48px | Major section breaks, vertical space between placeholder content blocks |
| 3xl | 64px | Page-level top/bottom padding on placeholder pages |

Exceptions: Header height is 64px (h-16 in Tailwind). Mobile drawer width is 288px (w-72 in Tailwind). Mobile touch targets minimum 44px.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px (text-base) | 400 (regular) | 1.5 | Placeholder page text, drawer nav links, footer text |
| Label | 14px (text-sm) | 400 (regular) | 1.4 | Desktop nav items, social link labels, copyright line |
| Heading | 24px (text-2xl) | 600 (semibold) | 1.2 | Placeholder page titles, site name in header |
| Display | 32px (text-3xl) | 600 (semibold) | 1.2 | Homepage placeholder hero text ("Michelle Ngo") |

Font family: `'Inter', ui-sans-serif, system-ui, sans-serif` declared via `@theme { --font-sans }` in app.css.

Source: D-05 (sans-serif throughout), DES-05 (modern typography with clear hierarchy), RESEARCH.md (Inter recommendation).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FFFFFF | Page background, header background (with 95% opacity + backdrop-blur), drawer background |
| Secondary (30%) | #F5F5F5 | Placeholder page content areas, footer background, hover backgrounds |
| Text primary | #1A1A1A | Headings, body text, nav items |
| Text secondary | #6B7280 | Copyright text, placeholder body copy, inactive states |
| Border | #E5E7EB | Header bottom border, drawer dividers |
| Accent (10%) | #4A6FA5 | See reserved list below |
| Accent hover | #3B5D8C | Hover state for accent-colored elements |
| Backdrop | rgba(0,0,0,0.3) | Mobile drawer backdrop overlay |

Accent reserved for:
1. Active/current navigation link indicator
2. Hovered navigation links (text color transition)
3. Social icon hover state
4. "Contact Me" link in footer on hover
5. Focus ring color for keyboard navigation (outline-color)

Accent is NOT used for: backgrounds, borders at rest, body text, headings, or placeholder content.

Source: D-06 (monochrome + one accent), D-08 (Claude picks muted steel blue — RESEARCH.md recommendation).

## Interaction Contract

### Navigation

| Interaction | Behavior |
|-------------|----------|
| Click nav link (desktop) | Navigate to route. Active link shows accent color. |
| Click hamburger (mobile) | Drawer slides in from right (fly x:300, 300ms). Backdrop fades in. |
| Click backdrop | Drawer slides out. Backdrop fades out. |
| Click close button (drawer) | Drawer slides out. Backdrop fades out. |
| Click nav link (drawer) | Navigate to route. Drawer closes. |
| Click social icon | Opens external URL in new tab (target="_blank", rel="noopener noreferrer"). |
| Keyboard: Tab through nav | Focus ring (2px accent color outline, 2px offset) on each focusable element. |
| Keyboard: Escape (drawer open) | Closes drawer. |

### Responsive Breakpoints

| Breakpoint | Width | Navigation behavior |
|------------|-------|---------------------|
| Mobile | < 1024px | Hamburger icon visible. Desktop nav hidden. |
| Desktop | >= 1024px (lg) | Full nav bar visible. Hamburger hidden. |

Source: D-03 (slide-out drawer), D-11 (flat nav bar), RESEARCH.md Pitfall 6 (use lg: not md: breakpoint for nav).

## Accessibility Requirements

| Element | Requirement |
|---------|-------------|
| Hamburger button | `aria-label="Open menu"` |
| Close button | `aria-label="Close menu"` |
| Drawer backdrop | `role="presentation"` (not interactive landmark) |
| Nav element | `<nav>` semantic element for both desktop and drawer |
| Social links | `target="_blank" rel="noopener noreferrer"`, aria-label per icon (no visible text label) |
| Active link | Visually distinct (accent color) + `aria-current="page"` |
| Focus visible | 2px accent outline, 2px offset on all interactive elements |
| Color contrast | Text primary (#1A1A1A) on white: 16.5:1 (AAA). Text secondary (#6B7280) on white: 5.0:1 (AA). Accent (#4A6FA5) on white: 4.6:1 (AA for large text, use with 16px+ or add underline for links). |
