    - Accept `open` prop as bindable: `let { open = $bindable(false) } = $props()`.
    - Import `fly` from `svelte/transition`, `navItems` and `socialLinks` from `$lib/config/navigation`, `{ page }` from `$app/stores`.
    - Import `SocialLinks` component.
    - When `open` is true, render:
      - Backdrop: `<div class="fixed inset-0 bg-black/30 z-40" onclick={() => open = false} role="presentation"></div>`
      - Drawer panel: `<nav transition:fly={{ x: 300, duration: 300 }} class="fixed top-0 right-0 h-full w-72 bg-white z-50 shadow-lg flex flex-col">` (per D-03 slide from right).
      - Top area: Close button (X icon, `<button class="self-end p-4" onclick={() => open = false} aria-label="Close menu">`). X icon is a 24x24 SVG.
      - Middle: Nav links in `<div class="flex flex-col px-6">`, each link `<a class="py-3 text-base text-gray-800 hover:text-accent transition-colors" onclick={() => open = false}>`. Active link gets `text-accent` + `aria-current="page"`.
      - Bottom (mt-auto): `<div class="mt-auto border-t border-gray-200 px-6 py-6">` containing `<SocialLinks size={24} />` in a `flex gap-6 justify-center` container (per D-04 social icons in drawer).

    - Import `{ base }` from `$app/paths`.
    - Structure: `<footer class="bg-gray-50 pt-12 pb-8">` containing `<div class="max-w-7xl mx-auto px-4 lg:px-8 flex flex-col items-center gap-4">`.
