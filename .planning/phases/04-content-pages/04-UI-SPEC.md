# Phase 4 — UI Design Contract

> Visual and interaction contract for the 5 content pages: About, Press/News, Resume/CV, Blog, and Contact form. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (SvelteKit + Tailwind v4 CSS-first) |
| Preset | not applicable |
| Component library | none (hand-built Svelte components) |
| Icon library | Inline SVGs (download arrow, external link arrow, envelope, checkmark, alert triangle) |
| Font | Inter (Google Fonts, variable weight 300-700, inherited from Phase 1) |

Source: Phase 1/3 UI-SPEC continuity. SvelteKit project -- shadcn not applicable.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tag/pill internal padding, inline spacing |
| sm | 8px | Card metadata spacing, form field gap between label and input |
| md | 16px | Card internal padding, grid gaps (mobile), form field vertical spacing |
| lg | 24px | Grid gaps (desktop), section heading to content spacing, about photo-bio gap |
| xl | 32px | Horizontal page padding (desktop), space between page sections |
| 2xl | 48px | Major section breaks (about bio to disciplines grid, resume sections) |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions: Contact form submit button has 44px minimum touch target height. PDF download button has 44px minimum touch target height. Form inputs are 40px height (10 * 4px).

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px (text-base) | 400 (regular) | 1.5 | Bio text, blog post body, resume descriptions, press item titles, form labels, contact message |
| Label | 14px (text-sm) | 400 (regular) | 1.4 | Breadcrumbs, press source/date, resume dates/company, blog post date/excerpt, form field labels, skill tags |
| Heading | 24px (text-2xl) | 600 (semibold) | 1.2 | Page titles (About, Press, Resume, Blog, Contact), resume section headings, blog post title on detail page |
| Display | 14px (text-sm) | 600 (semibold) | 1.4 | Resume metadata keys (uppercase), press source line (uppercase), discipline card label |

4 distinct sizes: 14px (label + display-label), 16px (body), 24px (heading). No display-scale heading needed for content pages -- consistent with Phase 3 inner pages.

Source: Phase 3 UI-SPEC typography, CONTEXT D-01 through D-15.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FFFFFF | Page backgrounds, form backgrounds, card backgrounds |
| Secondary (30%) | #F5F5F5 | About disciplines grid background band, resume section card backgrounds, blog card hover background |
| Text primary | #1A1A1A (text-gray-900) | Page headings, body text, form input text, blog post titles |
| Text secondary | #6B7280 (text-gray-500) | Metadata (dates, sources, companies), placeholder text, breadcrumbs, form labels |
| Text body | #374151 (text-gray-700) | Long-form body text (bio, blog posts, resume descriptions) for softer reading |
| Border | #E5E7EB (border-gray-200) | Card borders, form input borders, resume section dividers, press item dividers |
| Accent (10%) | #4A6FA5 | See reserved list below |
| Accent hover | #3B5D8C | Hover state for accent-colored elements |
| Success | #16A34A (green-600) | Contact form success state icon and text |
| Error/Destructive | #DC2626 (red-600) | Contact form error state, form validation errors |

Accent reserved for:
1. "Download Resume" button background
2. Contact form "Send Message" submit button background
3. Discipline card hover border on about page
4. Blog post title hover on blog index
5. External link icon on press items
6. Breadcrumb "Home" and parent links on hover
7. Focus ring on form inputs (2px accent outline, 2px offset)

Accent is NOT used for: card backgrounds at rest, body text, section backgrounds, or decorative elements.

Source: Phase 3 UI-SPEC color palette, Phase 1 accent #4A6FA5.

Components built or extended in this phase, with visual specs.

### About Page

| Property | Value |
|----------|-------|
| Route | /about/ |
| Top padding | 32px |
| Bottom padding | 64px |
| Max content width | 1280px (max-w-7xl), centered |
| Horizontal padding | 16px mobile, 32px desktop |

Layout (desktop): Split two-column grid. Left column (40% width): professional photo via ContentfulImage, rounded-sm (4px), aspect-ratio 3/4 portrait. Right column (60% width): bio heading + Rich Text body.

Layout (mobile): Single column, photo stacks above bio. Photo max-width 320px centered.

Contents (top to bottom):
- Breadcrumb: "Home / About" -- text-sm, text-gray-500
- Page heading: "About", text-2xl, font-semibold, text-gray-900, mt-4, mb-6
- Split layout: `grid grid-cols-1 lg:grid-cols-5 gap-8 lg:gap-12`
  - Photo column (lg:col-span-2): ContentfulImage with lazy loading, aspect-3/4, rounded-sm, object-cover
  - Bio column (lg:col-span-3): Rich Text rendered via RichText.svelte component. Body text text-base text-gray-700 leading-relaxed.
- Disciplines grid: mt-12 (48px), full width below split layout
  - Section heading: "Disciplines", text-2xl, font-semibold, text-gray-900, mb-6
  - Grid: `grid grid-cols-2 sm:grid-cols-3 lg:grid-cols-6 gap-4`
  - Each discipline card: border border-gray-200, rounded-sm, px-4 py-6, text-center, hover:border-accent transition-colors duration-200
    - Discipline name: text-sm, font-semibold, text-gray-900
    - Links to corresponding category page using CATEGORIES config

Source: CONTEXT D-01 (split layout), D-02 (CMS bio), D-03 (discipline cards link to category pages).

### Press/News Page

| Property | Value |
|----------|-------|
| Route | /press/ |
| Top padding | 32px |
| Bottom padding | 64px |
| Max content width | 1280px (max-w-7xl), centered |
| Layout | Chronological list grouped by year |

Contents (top to bottom):
- Breadcrumb: "Home / Press"
- Page heading: "Press", text-2xl, font-semibold, text-gray-900, mt-4, mb-8

Year group:
- Year heading: text-lg (18px), font-semibold, text-gray-900, mt-8 first:mt-0, mb-4
- Press items within year: stacked vertically, separated by border-b border-gray-200, py-4

Per press item:
- Source publication: text-sm, font-semibold, text-gray-500, uppercase, tracking-wider
- Title: text-base, font-semibold, text-gray-900, mt-1. Entire row is a link wrapping title. `hover:text-accent`
- Date: text-sm, text-gray-500, mt-1. Formatted as "Month Day, Year"
- External link indicator: inline SVG arrow icon (12x12px) after title, text-gray-400, `target="_blank" rel="noopener noreferrer"`

Source: CONTEXT D-11 (chronological feed, PressItem fields), D-12 (Claude's Discretion -- year-grouped list chosen).

### Contact Page

| Property | Value |
|----------|-------|
| Route | /contact/ |
| Top padding | 32px |
| Bottom padding | 64px |
| Max content width | 640px (max-w-xl), centered within 1280px container |
| Layout | Single column centered form |

Contents (top to bottom):
- Breadcrumb: "Home / Contact"
- Page heading: "Contact", text-2xl, font-semibold, text-gray-900, mt-4, mb-2
- Intro text: "Have a project in mind? Get in touch.", text-base, text-gray-500, mb-8
- Form fields (stacked vertically, gap-4 between fields):
  - Name field:
    - Label: "Name", text-sm, font-semibold, text-gray-700, mb-1
    - Input: w-full, border border-gray-200, rounded-sm, px-3 py-2.5 (40px height), text-base, text-gray-900, placeholder text-gray-400, focus:border-accent focus:ring-1 focus:ring-accent outline-none transition
  - Email field: Same styling as name. Input type="email".
  - Message field:
    - Label: "Message", text-sm, font-semibold, text-gray-700, mb-1
    - Textarea: w-full, border border-gray-200, rounded-sm, px-3 py-3, text-base, text-gray-900, min-h-[160px], resize-y, same focus styling as inputs
  - Honeypot field: hidden input (display:none) for Web3Forms spam protection. Not visible to users.
  - Submit button: w-full, bg-accent text-white, py-3 (48px height), rounded-sm, text-base font-semibold, hover:bg-accent-hover, transition-colors, cursor-pointer. Disabled state: opacity-50, cursor-not-allowed.

Form states (Claude's Discretion D-10 -- inline states, no redirect):
- Idle: Form fields visible, submit button reads "Send Message"
- Submitting: Submit button text changes to "Sending...", button disabled, opacity-50
- Success: Form fields replaced by success message block. Green checkmark icon (24x24px, text-green-600) centered above "Message sent" heading (text-lg, font-semibold, text-gray-900) and "Thank you for reaching out. Michelle will get back to you soon." body (text-base, text-gray-500). "Send another message" link below (text-sm, text-accent, hover:text-accent-hover) to reset form.
- Error: Red alert icon (24x24px, text-red-600) above error message. "Something went wrong" heading (text-lg, font-semibold, text-gray-900) and "Your message could not be sent. Please try again or email directly at {email}." body (text-base, text-gray-500). "Try again" button (text-sm, text-accent) to reset to idle.

Validation: HTML5 native validation (required attribute on all 3 fields, type="email" on email). No custom JS validation needed.

Source: CONTEXT D-08 (Web3Forms), D-09 (minimal fields), D-10 (Claude's Discretion -- inline states).

## Interaction Contract

### Contact Form

| Interaction | Behavior |
|-------------|----------|
| Focus input field | Border transitions from border-gray-200 to border-accent. 1px accent ring appears. |
| Submit with empty required field | HTML5 native validation tooltip. Form does not submit. |
| Submit with invalid email | HTML5 native email validation. Form does not submit. |
| Click "Send Message" | Button text changes to "Sending...", button disabled. POST to Web3Forms API. |
| Successful submission | Form fields fade out (Svelte fade, 200ms). Success message fades in (Svelte fade, 200ms). |
| Failed submission | Error message appears below form (Svelte fade, 200ms). Form fields remain visible for retry. |
| Click "Send another message" | Success block fades out. Empty form fades back in. |
| Click "Try again" | Error message clears. Form remains with user's entered data preserved. |

### Blog Navigation

| Interaction | Behavior |
|-------------|----------|
| Click blog card | Navigate to /blog/{slug}/. |
| Hover blog card | Card gets shadow-sm (subtle lift effect), 200ms transition. |

### Press Items

| Interaction | Behavior |
|-------------|----------|
| Click press item title | Opens external URL in new tab (target="_blank"). |
| Hover press item title | Text transitions to text-accent, 200ms. |

### Resume Download

| Interaction | Behavior |
|-------------|----------|
| Click "Download PDF" | Browser downloads or opens PDF file from SiteSettings resumePdf URL. Uses `download` attribute if same-origin, otherwise opens in new tab. |

### About Discipline Cards

| Interaction | Behavior |
|-------------|----------|
| Click discipline card | Navigate to corresponding portfolio category page. |
| Hover discipline card | Border transitions from border-gray-200 to border-accent, 200ms. |

### Responsive Breakpoints

| Breakpoint | Width | Behavior |
|------------|-------|----------|
| Mobile | < 640px (default) | 1-col grids, photo stacks above bio, form full width |
| Tablet | >= 640px (sm) | 2-col blog grid, 3-col discipline grid, press items unchanged |
| Desktop | >= 1024px (lg) | 3-col blog grid, 6-col discipline grid, about split layout, resume max-w-3xl |

## Accessibility Requirements

| Element | Requirement |
|---------|-------------|
| Contact form | Each input has associated `<label>` with `for` attribute matching input `id` |
| Contact form submit | `<button type="submit">` element, disabled state uses `aria-disabled="true"` |
| Contact form success/error | Use `role="status"` and `aria-live="polite"` for dynamic state changes |
| Contact honeypot | `aria-hidden="true"`, `tabindex="-1"` on hidden spam trap field |
| Press external links | `target="_blank" rel="noopener noreferrer"`, include visually hidden "(opens in new tab)" text |
| Resume download link | `<a>` element with `download` attribute where applicable |
| Blog post body | Semantic heading hierarchy within Rich Text (h2, h3 -- no h1 in body) |
| All pages breadcrumb | `<nav aria-label="Breadcrumb">` with `<ol>` list structure (reuse existing component) |
| Discipline card links | `<a>` elements, not `<div>` with onclick |
| Focus visible | 2px accent outline (#4A6FA5), 2px offset on all interactive elements (inherited from Phase 1) |
| Color contrast | All text meets WCAG AA. Green success #16A34A on white: 4.5:1 (AA). Red error #DC2626 on white: 4.6:1 (AA). |
