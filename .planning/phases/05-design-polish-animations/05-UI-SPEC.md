## Motion Contract

This is the primary deliverable of Phase 5. All values are locked decisions from CONTEXT.md.

### Scroll Entrance Animations (DES-02)

| Property | Value |
|----------|-------|
| Effect | Fade-up: opacity 0 to 1, translateY 20px to 0 |
| Duration | 400ms |
| Easing | ease-out (CSS) or cubicOut (Svelte) |
| Trigger | Element enters viewport at threshold 0.1 (svelte-inview) |
| Replay | Once only -- element stays visible after first entrance |
| Stagger | 75ms delay between sibling items in grids/lists |

**Elements that receive scroll animation:**
- Video thumbnail cards and grids (VideoThumbnailCard, category grids)
- Homepage category sections (HomepageCategorySection)
- About page photo and bio blocks (HomepageAboutSnippet, about page)
- Press items (HomepagePressHighlights, press page year groups)
- Blog post cards (blog index)
- Resume section cards (resume page)
- Discipline cards (about page)

**Elements that do NOT receive scroll animation:**
- Header and navigation (always visible, sticky)
- Footer
- Breadcrumbs
- Page headings and titles
- Body text paragraphs
- Form fields (contact page)
- Hero section (above the fold, already visible)

### Page Transitions (DES-03)

| Property | Value |
|----------|-------|
| Effect | Crossfade: old page fades out, new page fades in |
| Duration | 250ms |
| Implementation | SvelteKit `{#key}` pattern in +layout.svelte with `fade` transition |
| Scroll reset | Always scroll to top (0, 0) on route change |

### Timing Reference

| Context | Duration | Easing |
|---------|----------|--------|
| Micro-interaction (hover, focus) | 200ms | ease-out (existing) |
| Component transition (accordion, drawer) | 300ms | cubicOut (existing) |
| Scroll entrance animation | 400ms | ease-out (new) |
| Page crossfade | 250ms | ease-out (new) |
| Skeleton shimmer cycle | 1500ms | ease-in-out (new) |

### Reduced Motion

| Condition | Behavior |
|-----------|----------|
| `prefers-reduced-motion: reduce` | All scroll animations disabled (elements render at full opacity, no translate) |
| `prefers-reduced-motion: reduce` | Page crossfade transitions disabled (instant swap) |
| `prefers-reduced-motion: reduce` | Skeleton shimmer becomes static gray (no animation) |
| `prefers-reduced-motion: reduce` | Hover color transitions preserved (no motion involved) |
| `prefers-reduced-motion: reduce` | Accordion slide transition preserved (functional, not decorative) |

## Implementation Notes

### Animation Utility Pattern

Create a shared Svelte action (`use:scrollFadeIn`) or wrapper component (`<ScrollReveal>`) that:
1. Uses svelte-inview (already installed v4.0.4) with threshold 0.1
2. Applies opacity 0 + translateY(20px) initially
3. Transitions to opacity 1 + translateY(0) on enter
4. Accepts optional `delay` prop for stagger (0ms, 75ms, 150ms, etc.)
5. Respects prefers-reduced-motion via CSS media query or JS check
6. Fires once only (unobserve after first trigger)

### Page Transition Pattern

In `+layout.svelte`:
1. Import `page` from `$app/stores` and `fade` from `svelte/transition`
2. Wrap `{@render children()}` in `{#key $page.url.pathname}` with `in:fade` and `out:fade` at 250ms
3. Add `onNavigate` callback to scroll to top on route change

### Skeleton Shimmer Keyframes

Add to `src/app.css`:
```css
@keyframes shimmer {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
```

With a utility class or Tailwind `@theme` extension for the shimmer gradient.

### prefers-reduced-motion in app.css

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

This global rule disables all CSS animations/transitions. Svelte transition functions should additionally check `window.matchMedia('(prefers-reduced-motion: reduce)')` and set duration to 0.
